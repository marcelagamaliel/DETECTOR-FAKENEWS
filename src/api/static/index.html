Verificador de Notícias

Análise instantânea baseada em padrões linguísticos.

Como utilizar o sistema

  • - Insira o texto completo da notícia para análise.
  • - O conteúdo deve possuir ao menos 100 caracteres.
  • - Quanto mais contexto, mais precisa
  • - O sistema não armazena nenhum dado enviado.
  • - Este verificador não substitui a checagem humana.
  • - O resultado é baseado em padrões encontrados em bases reais de notícias.

Importante entender

O modelo identifica padrões linguísticos comuns em notícias reais e falsas com base no corpus Fake.Br. Como todo sistema baseado em aprendizado de máquina, pode apresentar limitações e incertezas. Utilize o resultado como um apoio, não como uma conclusão absoluta.
